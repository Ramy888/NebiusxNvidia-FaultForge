# FaultForge: recorded live runs

> **Hugging Face is used only to host these static files.** This page makes **no model calls**,
> and no NVIDIA model is called through Hugging Face. Every NVIDIA Nemotron call in the recordings
> went to **Nebius Token Factory**, and every test and repair ran in **Token Factory Sandboxes**.

FaultForge finds how a backend fails when its dependencies misbehave, then proves a repair against
the same failures. This page replays real runs recorded on 5–6 October 2026.

Source, documentation and how to run it live: https://github.com/Ramy888/NebiusxNvidia-FaultForge
